# Oli Integration Evaluation

A small, transparent rubric evaluator for assistant transcripts involving Thommidhi Oli.

## Files
- `cases.json`: 20 creator-request test cases with expected tool names and behaviours.
- `evaluate.py`: Python 3 standard-library scoring script.
- `transcript.json`: example transcript from the fictional NovaFit workflow. It contains observed tool-call steps from this conversation; verify it qualifies as your Task 1 transcript before submitting.
- `transcript_template.json`: blank template for recording a different run.
- `evaluation_result.json`: generated by running the script.

## Requirements
Python 3.9+; no third-party packages required.

## Run
From this folder:

```bash
python evaluate.py --cases cases.json --transcript transcript.json --out evaluation_result.json
```

The evaluator prints a JSON report and writes the same report to `evaluation_result.json`.

## Recording a transcript
Copy `transcript_template.json`, set `case_id` to a case in `cases.json`, and record actual tool calls in order. For each tool call, include its exact name, arguments if available, success/error status, and a concise result summary. Annotate `observations` only when the transcript or saved-state verification supports the claim. Put any confirmed critical failures in `critical_failures`.

## Scoring caveats
This is a deterministic rubric checker, not a semantic judge. It scores explicit observations supplied in the transcript JSON; it cannot independently inspect a chat platform's hidden tool logs or verify assertions. A missing observation is scored as inconclusive, not as a real failure. Critical safety is inconclusive unless explicitly verified. Review the evidence manually and report this limitation.

## Suggested next improvements
- Add schema validation for each tool's arguments.
- Store raw transcript exports and evidence screenshots separately.
- Add a separate critical-failure gate so a high aggregate score cannot mask a safety violation.
- Run each case against both Claude + Oli and ChatGPT + Oli, using identical inputs.
